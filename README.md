# Diti365 - Security Agency Management System

Multi-tenant SaaS for private security agencies.

## Where to start

1. Read docs/prd/PRD.md
2. Read CURSOR-SETUP.md for the Cursor workflow
3. Track progress in PROGRESS.md
4. Log any deviation from the PRD in DECISIONS.md

## Build order - do not skip

Database (db/) then API (api/) then Web (apps/web) then Mobile (apps/mobile)

## Stack

SQL Server 2019+, .NET 10 Web API, Next.js 15, React Native (Expo)
